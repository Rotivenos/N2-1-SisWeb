# Sistema de Recomendação de Produtos para E-commerce

Descrição:
Em um sistema de e-commerce, a ideia é sugerir produtos personalizados para o usuário com base em seu histórico de navegação e compras anteriores. Para isso, vamos usar uma fila para gerenciar as requisições de recomendação, um banco NoSQL para armazenar os dados de usuários e produtos, e Lambdas para processar essas recomendações de forma escalável e eficiente.
